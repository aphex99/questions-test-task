# Interview Questions

SPA-приложение для подготовки к собеседованиям. Каталог вопросов с комбинированной фильтрацией, поиском, серверной пагинацией и просмотром подробных ответов

**[Live Demo](https://questions-test-task.vercel.app/)**

## Технологии

- **React 19, TypeScript** — пользовательский интерфейс и типизация
- **Redux Toolkit** — управление глобальным состоянием
- **RTK Query** — взаимодействие с REST API и кэширование серверных данных
- **React Router** — маршрутизация
- **SCSS, CSS Modules** — стилизация компонентов
- **Vite** — сборка приложения
- **ESLint, Prettier, Stylelint** — контроль качества и форматирование кода

## Функциональность

### Каталог вопросов

- Серверная пагинация с сохранением номера страницы в URL
- Поиск по названию вопроса с debounce (500 мс)
- Комбинированная фильтрация по специализации, навыкам, сложности и рейтингу
- Сброс пользовательских фильтров

### Карточка вопроса

- Просмотр краткого и развёрнутого ответов
- Отображение сложности, рейтинга, навыков и ключевых слов
- Навигация между вопросами с автоматической загрузкой соседних страниц
- Сохранение контекста фильтрации при переходах между вопросами

### Работа с API и обработка состояний

- Кэширование запросов с RTK Query
- Централизованная конфигурация API с автоматическими повторными запросами при ошибках
- Skeleton-компоненты для состояний загрузки
- Обработка ошибок API и возможность повторного запроса
- Empty State для отсутствующих результатов
- Error Boundary для обработки ошибок рендеринга
- Code splitting и lazy loading страниц и отдельных компонентов

## Архитектура

Структура проекта основана на методологии Feature-Sliced Design (FSD):

- `app` — инициализация приложения, провайдеры, маршрутизация и глобальные стили
- `pages` — страницы каталога и отдельного вопроса
- `widgets` — составные блоки интерфейса
- `features` — поиск и фильтрация вопросов
- `entities` — бизнес-сущности
- `shared` — переиспользуемые UI-компоненты, хуки, утилиты и API-конфигурация

Для контроля архитектурных зависимостей используется `eslint-plugin-boundaries`

## Локальный запуск

**Установка зависимостей**

```bash
pnpm install
```

**Запуск приложения**

```bash
pnpm dev
```

Приложение доступно по адресу `http://localhost:3000`

**Проверка кода и типов**

```bash
pnpm lint
pnpm typecheck
```

**Production-сборка**

```bash
pnpm build
```

## Деплой

Приложение размещено на Vercel. Проксирование API настроено через Vite для локальной разработки и через Vercel для production-окружения
